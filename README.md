# GPS Extractor - Globe FO Engineer Contact

A professional Streamlit application for extracting GPS coordinates and contact information from Globe FO Engineer data.

## Features

- 📍 **GPS Extraction**: View site locations with latitude/longitude coordinates
- 🗺️ **One-Click Navigation**: Navigate to any site directly in Google Maps
- 📞 **Click-to-Call**: Call FO engineers directly from the app
- 🎯 **Smart Filtering**: Filter by region, tower company, or coordinates availability
- 📊 **Statistics Dashboard**: Quick overview of your data
- ⬇️ **Export Data**: Download filtered or complete datasets as CSV
- 📱 **Mobile Responsive**: Works perfectly on both desktop and mobile devices

## Tech Stack

- **Framework**: Streamlit
- **Data Processing**: Pandas
- **Excel Support**: OpenPyXL
- **Styling**: Custom CSS with modern design
